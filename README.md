# 月球 LUNA · 观测器

一个 3D 月球观测网页：**NASA 真实月面数据**（LRO LOLA 高程 + LROC WAC 底图）+ 程序化微细节，
复刻抖音视频《Yan Agent + DeepSeek 生成的月球》里那套观测界面。

## 两种月面数据模式

**① 真实数据模式（推荐）——双击 `启动.command`**

用 NASA 实测数据渲染：**LRO LOLA 激光测高**（5760×2880，1.9 km/纹素）+ **LROC WAC 全球底图**（4096×2048 反照率）。
月海轮廓、撞击坑形状、辐射纹分布全部是真实月面，起伏读到的是真实值（−10.7 ~ +9.0 km）。

数据源自 **NASA SVS「CGI Moon Kit」**（公有领域，建议署名 NASA's Scientific Visualization Studio / LRO）。
本目录 `data/` 里是已转好的格式（见 `_dev/build_real_data.py`，可重新生成/换分辨率）。

> 真实数据必须经 HTTP 读取（浏览器不允许 `file://` 页面读本地二进制），所以给了启动器：
> 双击 **`启动.command`** → 自动起本地服务器并打开页面，关掉终端窗口即停止。

**② 程序化模式（离线兜底）——双击 `index.html`**

无需任何数据文件，月面在浏览器里实时生成，同样可看（左下角会显示「程序化生成」）。
用 `file://` 打开时，或 `data/` 缺失时，自动走这条路径。

## 功能

- **视角预设**：默认视角、定位地球、满月（α=0°）、上弦（α=90°）、贴近日下点·看地貌、月面特写（约 600 km 高度）
- **光照 · 相位**：太阳–地球夹角 α（0~180°）、曝光、地球反照（夜面补光）、冲日增亮（后向散射）
- **地貌**：垂直夸张（0~3×）、月面微尘颗粒、线框地形、经纬网格
- **场景**：星空、地球、地标标注、相机自动环绕、月球自转（演示）
- **地标标注**：静海、雨海、第谷坑、哥白尼坑等 20 处真实月面地名，随视角自动显隐

## 实现要点

- 月面地形：可平铺梯度噪声（大尺度）+ 真实月海经纬坐标（40 余个圆盘拼出风暴洋/雨海/静海…）+
  9.5 万个按幂律分布的撞击坑（含坑唇/坑形/中央峰/溅射毯剖面）+ 第谷等坑的辐射纹系统
- 渲染：单个全屏片元着色器解析求交球面，屏幕足迹自适应采样高程纹理得到法线（远处自动平滑、近处自动锐利），
  Lommel–Seelig​er 型月面散射 + 冲日效应 + 地球反照，地形沿半径位移（临边呈真实起伏）
- 观测数据全部实时反算：相机距月心、视场内分辨率、相位角、明亮比、日下点（含 1.54° 天平动倾角）、
  真实起伏（由生成的高程图统计得出）
